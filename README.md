# pulse-monitor
Легковесный монитор сети и системы для Windows. Показывает IP, нагрузку на ЦП/ОЗУ/Диск и ведет историю в SQLite. Жрет меньше памяти, чем Диспетчер Задач! Баги и ошибки пишите в Issues.


# 🩺 Pulse Monitor

**Pulse Monitor** — это легковесный сетевой и системный монитор, написанный на Python (PyQt6). 
Программа создана для быстрого получения информации о состоянии вашего ПК и сети.

## 📊 Характеристики

* **Потребление ОЗУ:** ~1.0 МБ (в 10 раз меньше, чем стандартный Диспетчер Задач Windows!).
* **Потребление ЦП:** 0% в фоновом режиме.
* **Скорость обновления:** 1 секунда (система), 30 секунд (сеть).
* **Поддержка ОС:** Windows 10 / 11 (64-bit).
* **База данных:** SQLite (хранит последние 250 записей).

## ✨ Основные возможности

* 🌐 **Сетевой монитор:** Отображает текущий публичный IP-адрес с автообновлением (каждые 30 сек) и задержку (ping).
* 📈 **Системный монитор:** В реальном времени показывает загрузку Процессора, Оперативной Памяти и Дискового пространства. 
* 📜 **История действий:** Ведет локальный журнал (SQLite) всех действий: запуск программы, ручная проверка IP, копирование в буфер и т.д.
* 🎨 **Дизайн:** Современная темная тема, минимализм, адаптивная верстка (под разные разрешения экрана).
* 🚀 **Оптимизация:** Минимальное потребление ресурсов. Используются асинхронные запросы и легковесные виджеты.
